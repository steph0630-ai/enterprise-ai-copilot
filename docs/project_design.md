# 项目设计文档

> 企业智能知识库 Agent —— 技术设计文档 v1.0

## 1. 项目定位

我做的是一个**企业智能知识库 Agent**，不是普通聊天机器人。

> **一句话护城河**：ChatGPT 不知道企业内部私有文档；我的 Agent 基于企业自己的知识库回答"我们公司的报销流程是什么"——这是通用大模型永远答不上来的。

## 2. 项目背景（痛点）

企业内部存在大量文档，比如：

- 需求文档
- 员工手册
- 合同模板
- （产品文档 / 技术文档 / SOP 流程 / FAQ 等）

员工查询这些信息的成本高——要翻几十页、问同事、在文件夹里大海捞针，**花费大量时间、效率低、找不到**。

## 3. 解决方案

我设计一个 AI Agent，通过 **RAG** 检索企业知识，再结合**工具调用**完成智能问答，让员工用**自然语言**就能查到公司内部知识。

> 关键：员工**不需要懂 SQL**。Agent 负责把自然语言翻译成检索/SQL，员工只管说人话。

## 4. 用户角色

| 角色 | 能做什么 |
| --- | --- |
| 员工 | 用自然语言查询知识、查看自己的历史对话 |
| 部门管理员 | 上传和管理本部门文档、查询本部门及公共知识库 |
| 超级管理员 | 管理全部知识库、用户部门和角色 |
